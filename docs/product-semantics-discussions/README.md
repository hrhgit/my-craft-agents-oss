# 产品语义讨论纪要

本目录保留每次产品语义讨论的过程，便于追溯结论为什么形成。它不是规范本身；已经达成共识的结论必须同步写入 [`../product-semantics.md`](../product-semantics.md) 或对应的专题语义文档。

## 何时记录

讨论涉及产品概念、用户可见行为、归属边界、生命周期、权威来源或重要不变量时，均须创建纪要。纯实现细节、排错过程和不改变产品含义的局部代码选择不在此记录。

## 写入规则

- 每次讨论一份文件，命名为 `YYYY-MM-DD-简短主题.md`；同日同主题有多次独立讨论时追加序号。
- 使用 [`_template.md`](_template.md) 记录时间点、观点、冲突、依据与共识。时间使用中国标准时间并标明时区。
- 用户明确同意执行讨论结果即为讨论结束节点。先完成纪要及相应语义文档更新，再开始代码、配置或其他实现改动；在“语义文档落点”中列出更新后的文档和章节。
- 没有形成结论时明确写“待决定”，并说明阻塞原因；在此之前不得将讨论中的观点当作既有产品语义实施。
- 纪要按发生顺序追加事实，不重写历史观点；后续讨论通过新的纪要修正或取代旧共识，并在新的语义文档落点中说明关系。

# 共享界面交互

## 范围

本模块提供按钮、输入框、开关、空状态、提示、主题和翻译等可复用基础。它不定义业务流程。

## 稳定合同

| 交互 ID | 行为 | 可观察结果 | 验证 |
| --- | --- | --- | --- |
| `ui.control.activate` | 用键盘或指针触发可用控件 | 只触发一次命令，焦点轮廓清晰 | `shared-ui.controls` |
| `ui.theme.switch` | 切换明暗主题 | 字体、边界和状态色保持可读 | `shared-ui.themes` |
| `ui.locale.switch` | 切换语言 | 当前页面文案更新且布局不溢出 | `shared-ui.locales` |

业务脚本应依赖语义标识、角色和可访问名称，不依赖 CSS 类名或元素层级。

业务表单的分栏断点以所在面板宽度为准，不以外层窗口宽度代替；窄面板不得因双栏或长标签产生横向滚动。

当前批量 flow：`shared-ui.shell-semantics`。
